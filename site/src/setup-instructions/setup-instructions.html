Connect through osrs-data-hub

This map gets player data from the guild's osrs-data-hub. Players do not pair with the map: once your RuneLite plugin is paired with the hub and your account's live location is shared with the guild, you appear here automatically.

  1. Install the RuneLite HomeAssistant Data Exporter plugin from the Plugin Hub.
  2. Sign in to the hub and follow its onboarding to get a pairing code.
  3. Enter the code in the plugin. You show up on the map within a few seconds of logging in.
  4. Not showing up? In the hub's sharing settings, share your live location (and stats) with the guild.

Device Pairing

Generate a pairing code and enter it in the RuneLite plugin to link a player's client to the group. Each code expires after 5 minutes.

Setup

This app requires each group member to install a RuneLite plugin from the Plugin Hub in order to track player information. After installing the plugin, use device pairing to link each player's client to the group.

Steps:

  1. Install the RuneLite plugin from the Plugin Hub.
  2. Click "Generate Pairing Code" above to get a 5-digit code.
  3. Enter the code in the RuneLite plugin to pair your device.
  4. Once paired, player data is automatically ingested.
